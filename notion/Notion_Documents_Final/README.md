## 📝 노션 Import 방법

1. 노션 페이지에서 `/import` 입력
2. 각 MD 파일 선택하여 import
3. 계층 구조에 맞게 페이지 정리

### 권장 구조

```
📌 3DaysOfAI 과정
├── 과정 소개
├── 📅 Day 1
│   ├── Overview
│   ├── Step 1
│   ├── Step 2
│   ├── Step 3
│   ├── Step 4
│   └── Step 5
├── 📅 Day 2
│   ├── Overview
│   ├── Step 1
│   └── Step 2
└── 📅 Day 3
    └── Overview
```

## 🎯 문서 특징

- **실습 중심**: 각 Step마다 실행 가능한 코드 파일
- **단계별 학습**: 이전 Step 내용을 기반으로 발전
- **체크리스트**: 학습 진도 관리
- **명확한 목표**: 각 실습의 학습 목표 명시
