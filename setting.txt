================================================================================
                     3DaysOfAI - 환경 설정 가이드
================================================================================

이 문서는 3DaysOfAI 프로젝트를 새로운 환경에서 실행하기 위한 설정 방법을 설명합니다.

--------------------------------------------------------------------------------
1. 필수 요구사항
--------------------------------------------------------------------------------

- Python 3.10 이상 (권장: 3.12)
- Snowflake 계정 (Cortex AI 사용 가능)
- 인터넷 연결

--------------------------------------------------------------------------------
2. Python 패키지 설치
--------------------------------------------------------------------------------

터미널/명령 프롬프트에서 프로젝트 폴더로 이동 후 실행:

    pip install -r requirements.txt

설치되는 패키지:
- streamlit >= 1.31.0
- snowflake-snowpark-python >= 1.11.1
- PyPDF2 >= 3.0.0
- numpy >= 1.24.0
- pandas >= 2.0.0

--------------------------------------------------------------------------------
3. Snowflake 연결 설정
--------------------------------------------------------------------------------

[중요] .streamlit/secrets.toml 파일을 본인의 Snowflake 계정 정보로 수정하세요.

파일 위치: .streamlit/secrets.toml

파일 내용:
--------------------------------------------------------------------------------
[connections.snowflake]
account = "YOUR_ACCOUNT"           # Snowflake 계정 (예: abc12345.us-west-2)
user = "YOUR_USERNAME"             # 사용자 이름
password = "YOUR_PASSWORD"         # 비밀번호
role = "YOUR_ROLE"                 # 역할 (예: ACCOUNTADMIN)
warehouse = "YOUR_WAREHOUSE"       # 웨어하우스 (예: COMPUTE_WH)
database = "YOUR_DATABASE"         # 데이터베이스
schema = "PUBLIC"                  # 스키마
--------------------------------------------------------------------------------

Snowflake 계정 정보 확인 방법:
1. Snowsight (https://app.snowflake.com) 로그인
2. 좌측 하단 계정 이름 클릭 → "계정 세부 정보 보기"
3. Account Identifier 확인

5. 실행 방법
--------------------------------------------------------------------------------

1) 터미널에서 프로젝트 폴더로 이동:

   cd 3DaysOfAI

2) 실습 파일 실행:

   # Day1 실습
   cd problems/Day1
   streamlit run app_1_1.py

   # 또는 정답 확인
   cd solutions/Day1
   streamlit run app_1_1.py

3) 브라우저에서 자동으로 열리거나, 터미널에 표시된 URL로 접속
   (기본: http://localhost:8501)

7. 사용되는 모델
--------------------------------------------------------------------------------

기본 모델: llama3.1-70b (Meta의 70B 파라미터 대형 모델)

사용 가능한 다른 모델:
- mixtral-8x7b
- mistral-7b
- snowflake-arctic

모델 변경 방법:
코드에서 complete_llm() 함수 호출 시 모델명 변경
예: complete_llm(session, "mixtral-8x7b", prompt)

--------------------------------------------------------------------------------
8. 문제 해결
--------------------------------------------------------------------------------

[오류] Snowflake 연결 실패
→ secrets.toml 파일의 계정 정보 확인
→ 방화벽/네트워크 설정 확인

[오류] 모듈을 찾을 수 없음
→ pip install -r requirements.txt 다시 실행

[오류] LLM 호출 실패 (400 Bad Request)
→ Snowflake Cortex가 계정/지역에서 활성화되어 있는지 확인
→ 다른 모델로 시도 (예: mixtral-8x7b)

[오류] 한국어 응답이 이상함
→ 시스템 프롬프트에 "한국어로 답변하세요" 포함 확인
→ 더 큰 모델 사용 (llama3.1-70b 권장)

--------------------------------------------------------------------------------
9. 기술 스택 요약
--------------------------------------------------------------------------------

- UI: Streamlit
- LLM: Snowflake Cortex AI (SQL 방식)
- 임베딩: snowflake-arctic-embed-m
- 언어: Python 3.12

LLM 호출 방식:
```python
def complete_llm(session, model, prompt):
    escaped_prompt = prompt.replace("'", "''")
    sql = f"SELECT SNOWFLAKE.CORTEX.COMPLETE('{model}', '{escaped_prompt}')"
    return session.sql(sql).collect()[0][0]
```
