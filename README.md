## 🚀 빠른 시작

```bash
# 1. 설치
pip install -r requirements.txt

# 2. Snowflake 설정
# .streamlit/secrets.toml 파일에 계정 정보 입력

# 3. 실행
cd problems/Day1
streamlit run app_1_1.py
```
